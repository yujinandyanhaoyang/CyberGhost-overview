# CyberGhost

让主体理解宿主已有能力，携带目标、记忆和进度在异构设备间继续工作。

[English](README.md) | 简体中文

## 研究目标

研究一套共同的发现、理解、验证、规划、执行和迁移流程。主体进入获授权的宿主后，读取其已有框架、SDK及技能资料，核实能力与接口映射，利用现有身体和动作继续任务。

两条轴共同验收。

- **持续性**涵盖目标、有效记忆、已确认进度和执行权。
- **宿主适应**涵盖新宿主能力获取、语义理解、接口适配与据此重规划。

设备连接器和专属知识逐项记录。我们希望测出主体能够自动取得或生成的部分，以及所需人工投入。

## 当前证据

已独立核验的CG73R1覆盖声明通信图变化、授权前明确拒绝和未知回执三个固定场景，技能在受控隔离软件进程内执行。CG74另通过两个直连中断固定场景，在权威账本仍可达时核验撤销确认、替代路线及迟到激活拒绝。此前ROS 2 mock与Linux/Windows结果各有版本和范围。

新宿主自主理解、真实物理迁移、任意机器人泛化、外部采用和经济收益仍待验证。[软件证据与边界](SOFTWARE_STATUS.md)

RAX与本项目的宿主适应目标高度相关，其实机适配设计已纳入组件复用审查。与现有方法相比，持续性和宿主适应结合能产生何种增量，需要直接对照。[RAX论文](https://arxiv.org/abs/2610.22496) · [实机适配指南](https://github.com/robot-agent-exploration/rax/blob/main/docs/REAL_ROBOT_ADAPTATION.md)

## 希望共同验证什么

先选一个有真实结果可观察的有限物理任务，复用设备已有技能和接口，再争取具有不同接口或能力的第二宿主。接入第二宿主前冻结主体核心，完整记录专属适配和人工修改。

需要SDK或技能文档、单位/坐标系、前置条件、完成/查询/停止语义、部署及通信许可、具名技术评审人。真实集成或任务中断案例及现有处理方式，可帮助确定有价值的对照。

衡量任务结果、能力理解、错误调用、人工修改量和适配时间。持续性对照包含获得同等任务信息的持久协调器。实机测试按设备具体范围和授权进行。
